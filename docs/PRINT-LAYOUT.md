# Макеты печати — «Ветераны» (v1, условные)

Макеты составлены по описанию из ТЗ. Официального бумажного бланка нет, поэтому
это **рабочая версия**: её можно принять как есть или править после первого
пробного оттиска. Все размеры — в миллиметрах, координаты от верхнего левого угла
области печати (после полей).

---

## 1. Общие параметры

| Параметр | Карточка (одна запись) | Список записей |
|---|---|---|
| Формат | A4, книжная | A4, **альбомная** |
| Поля | Л 20 / П 15 / В 15 / Н 15 | Л 15 / П 15 / В 15 / Н 15 |
| Шрифт | Noto Sans (встроен в поставку) | Noto Sans |
| Основной кегль | 10 pt | 9 pt |
| Межстрочный | 1.15 | 1.0 |
| Цвет | только чёрный (без серых заливок) | чёрный + заливка шапки 5 % |
| Нумерация | не нужна (1 запись = 1 страница) | «Стр. X из Y», по центру снизу |

Правила отображения пустых значений: везде печатается **«—»**, поле не пропадает
(иначе бланк «прыгает»). Месяц посещения — словом в именительном падеже
(«март 2026»: в карточке значение стоит отдельной строкой, без предлога, поэтому
именительный падеж верен; родительный нужен только в полной дате «1 марта 2026»;
в списке — только год).

Толщина линий: `QTextDocument` рисует рамки таблиц только в `px`, значения в `pt`
в таблицах молча отбрасываются (проверено отрисовкой в `QImage`: линия `0.75pt`
не появляется вовсе). Поэтому в коде вместо `0.75 pt` стоит `1 px`
(1 px при 96 dpi = 0.2646 мм = 0.75 pt), а вместо рамки `0.5 pt` — тоже `1 px`
как минимально возможная толщина. Визуально это совпадает с макетом.

Единицы в HTML карточки: документ верстается в логических 96 dpi и
масштабируется на устройство печати, поэтому `px` в шаблоне — это 1/96″, а
миллиметры макета переведены в `px` (6 мм = 23 px, 10 мм = 38 px).
`pt` и `mm` в полях (`margin`/`padding`) Qt не применяет — тоже проверено
отрисовкой.

Нумерация на карточке: `QTextDocument::print()` сам добавляет номер страницы в
правом нижнем углу, поэтому страницы рисуются вручную через `QPainter` —
по макету нумерация карточке не нужна, а номер остаётся только у списка
(«Стр. X из Y»).

## 2. Карточка ветерана (печать из формы и режим «каждую отдельно»)

```
┌────────────────────────────────────────────────────────────┐  ← верх области
│                ГОСПИТАЛЬ ВЕТЕРАНОВ                         │  ← 14 pt, bold, по центру
│              (наименование из настроек)                    │  ← 9 pt, по центру
│                                                            │
│ ────────────────────────────────────────────────────────── │  ← линия 0.75 pt = 1 px, 10 мм от шапки
│                                                            │
│ КАРТОЧКА ВЕТЕРАНА                          № 000123        │  ← 12 pt / 10 pt, справа
│                                                            │
│ ┌────────────────────────────────────────────────────────┐ │  ← рамка 0.5 pt = 1 px, 8 мм отступ
│ │ ФИО                                                    │ │  ← 7.5 pt, uppercase
│ │ ИВАНОВ ИВАН ИВАНОВИЧ                                   │ │  ← 15 pt, bold
│ └────────────────────────────────────────────────────────┘ │
│                                                            │
│ Дата рождения: 12.03.1948        Микрорайон: 7             │  ← 10 pt, два поля в строку
│                                                            │
│ Адрес прописки:                                            │  ← 7.5 pt, uppercase
│ ул. Ленина, д. 15, корп. 2, кв. 41                         │  ← 11 pt
│                                                            │
│ Телефон: X-XX-XX (домашний)                                │  ← 11 pt
│                                                            │
│ Льготная категория:                                        │
│ Ветеран труда                                              │  ← 11 pt
│                                                            │
│ Дата посещения госпиталя:                                  │
│ март 2026                                                  │
│                                                            │
│ Подписка на газету:                                        │
│ Ветеран, 2026                                              │
│                                                            │
│ ────────────────────────────────────────────────────────── │
│ Дата формирования: 19.11.2026        Подпись: ___________  │  ← 8 pt
└────────────────────────────────────────────────────────────┘  ← низ области
```

Порядок сверху вниз жёстко фиксирован ТЗ: **ФИО → дата рождения → адрес
(микрорайон, улица, дом, корпус, квартира) → телефон → льготная категория →
дата посещения госпиталя → подписка на газету**. Подписи полей — над значением,
значения выровнены по левому краю; «дата рождения» и «микрорайон» стоят в одной
строке (как в форме ввода). Телефон печатается в формате из справочника:
`X-XX-XX` для домашнего и `+7XXXXXXXXXX` для мобильного, с подписью типа в
скобках; если телефон не указан — строка не печатается. ФИО — единственный элемент, который выделен рамкой и крупным
кеглем, чтобы карточку было легко найти в пачке.

Если карточка не помещается на страницу (очень длинный адрес) — перенос адреса
на две строки, блоки ниже сдвигаются, но карточка **никогда не разрывается**
между страницами.

## 3. Список записей (печать отмеченных галочками)

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                              СПИСОК ВЕТЕРАНОВ                                │  ← 13 pt bold, центр
│ Сформировано: 19.11.2026                                    Записей: 12      │  ← 8 pt
├────┬────────────────────────┬────────────┬────────┬─────────────────┬────────┤
│ №  │ ФИО                    │ Мкр.       │ Год    │ Льготная        │ Год    │  ← шапка 8 pt bold,
│    │                        │            │ рожд.  │ категория       │ посещ. │    заливка 5 %
├────┼────────────────────────┼────────────┼────────┼─────────────────┼────────┤
│ 1  │ Иванов Иван Иванович   │ 7          │ 1948   │ Ветеран труда   │ 2026   │  ← 9 pt, высота 7 мм
│ 2  │ Петрова Анна Сергеевна │ 12         │ 1951   │ Инвалид         │ 2025   │
│ 3  │ ...                    │ ...        │ ...    │ ...             │ ...    │
└────┴────────────────────────┴────────────┴────────┴─────────────────┴────────┘
                                                              Стр. 1 из 2        ← 8 pt, центр
```

Ширины колонок (сумма 267 мм при полезной ширине 267 мм):

| Колонка | Ширина | Выравнивание |
|---|---|---|
| № | 12 мм | по центру |
| ФИО | 75 мм | слева |
| Мкр. | 24 мм | по центру |
| Год рождения | 22 мм | по центру |
| Льготная категория | 58 мм | слева |
| Год посещения | 26 мм | по центру |
| Подписка на газету | 50 мм | слева (в формате «Ветеран, 2026») |

Правила:
- чекбоксы, панель инструментов и служебные элементы на печать **не попадают**;
- печатаются только отмеченные записи, в том порядке, в котором они стоят в
  таблице на экране (с учётом текущей сортировки);
- шапка таблицы повторяется на каждой странице;
- «Мкр.» — сокращение «Микрорайон»: полное слово в 8 pt шире колонки 24 мм
  и вылезало за её границы;
- длинное ФИО/категория переносится на вторую строку внутри ячейки, высота
  строки увеличивается, разрыв строки между страницами запрещён; неразрывное
  слово (длинная фамилия без пробелов) переносится по буквам, а не вылезает
  за границы ячейки;
- если отмечено 0 записей — кнопка «Печать» неактивна (см. ТЗ).

---

## 4. Режим «Печатать каждую запись отдельно»

Карточки из раздела 2 идут последовательно, **каждая с новой страницы**, шапка
(«Госпиталь ветеранов» + линия) повторяется на каждой странице. Порядок — как в
списке. Номер карточки = `id` записи в базе, дополненный нулями до 6 знаков.

Альтернатива, если заказчик попросит экономию бумаги: печатать по две карточки на
лист с линией разреза — вынести в настройку печати (по умолчанию — одна на лист).

## 5. Открытые вопросы по макету (закрываются пробным оттиском)

1. Нужны ли логотип/реквизиты учреждения в шапке карточки?
2. Нужна ли подпись сотрудника и расшифровка, или достаточно строки «Подпись»?
3. Нужен ли номер карточки (id) на бумаге, или это внутренняя информация?
4. Печатать ли «Дата рождения» полностью или только год (как в таблице на экране)?
   По ТЗ в форме — полная дата, поэтому в карточке печатаем полностью.
5. Нужна ли отдельная графа «Примечание» — в ТЗ её нет, но на бумаге часто просят.
