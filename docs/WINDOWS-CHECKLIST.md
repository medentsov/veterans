# Проверка на Windows — чеклист v1

Пошаговый список для прогона на целевой машине. Закрывает пункты плана
**M1-07, M11-04, M8-06, M12-04, M12-05, M12-08**.

Как пользоваться:

1. Идите сверху вниз, отмечая `[x]` только после фактической проверки.
2. Если шаг не прошёл — не отмечайте его, запишите симптом в конце раздела и
   приложите вывод консоли и `logs\app.log`.
3. Заполненные разделы 0 и 9 пришлите разработчику — по ним обновляется
   `docs/PLAN.md`.

Требования к машине: **Windows 10 или 11, x64** (ARM64 не подходит: под MinGW
нет сборки Qt). Windows 11 Pro/Enterprise удобнее — есть Windows Sandbox для
проверки «чистой машины».

## 1. Установка ПО

- [ ] Qt 6.5.3 (или новее) с компонентами: Qt Widgets, Qt Sql, Qt PrintSupport, MinGW 11.2.0 64-bit
- [ ] CMake 3.21+ (в `PATH`)
- [ ] Git for Windows
- [ ] Inno Setup 6 (нужен только для установщика, раздел 5)
- [ ] `C:\Qt\6.5.3\mingw_1120_64\bin` и `C:\Qt\Tools\mingw1120_64\bin` в `PATH`
- [ ] Проверка в новой консоли: `cmake --version`, `windeployqt --version`, `g++ --version` отвечают

## 2. Получение исходников

Репозиторий приватный, нужен вход.

- [ ] `gh auth login` (или `git clone` с логином/токеном)
- [ ] `gh repo clone medentsov/veterans`
- [ ] `cd veterans` — в каталоге видны `CMakeLists.txt`, `build.ps1`, `src`, `tests`

## 3. Сборка и автотесты — M1-07

- [ ] Выполнено: `powershell -ExecutionPolicy Bypass -File build.ps1 -Tests`
- [ ] Сборка завершилась без ошибок
- [ ] Найден `build\release\Veterans.exe`
- [ ] Рядом с exe лежат DLL Qt (например, `Qt6Core.dll`, `Qt6Widgets.dll`) и каталоги `platforms\`, `styles\`
- [ ] Автотесты вывели «Проверок: 97, провалов: 0»

Если тесты не собрались — повторить с `-DVETERANS_BUILD_TESTS=ON` вручную:
`cmake --preset release -DVETERANS_BUILD_TESTS=ON` → `cmake --build --preset release`.

## 4. Первый запуск — M1-07

Запускать **из `build\release`**, при закрытом Qt Creator (чтобы не подхватить
DLL из IDE).

- [ ] `Veterans.exe` открывается, окно не пустое, таблица и панель на месте
- [ ] Рядом с exe созданы: `data\veterans.db`, `logs\app.log`, `backups\`, `settings.ini`
- [ ] В `logs\app.log` есть строки «Запуск … режим: portable» и «База данных: …»
- [ ] Создана запись: ФИО, дата рождения, микрорайон 1–999, телефон (домашний `X-XX-XX` и мобильный `+7XXXXXXXXXX`)
- [ ] Запись видна в таблице, открывается на правку, сохраняется
- [ ] Сортировка по всем 7 колонкам работает, быстрый поиск фильтрует, счётчик меняется
- [ ] Расширенный поиск по 6 критериям работает, «Сбросить» очищает фильтр
- [ ] Удаление спрашивает подтверждение и убирает запись
- [ ] После перезапуска данные на месте
- [ ] Смена темы в настройках применяется без перезапуска
- [ ] Масштаб Windows 125 % и 200 %: интерфейс не «плывёт», текст читаем

## 5. Упаковка и чистая машина — M11-04

- [ ] `powershell -ExecutionPolicy Bypass -File tools\package-portable.ps1`
- [ ] Получен `dist\Veterans-portable.zip`, в нём `Veterans.exe`, DLL, `platforms\`, `data\`, `logs\`, `backups\`
- [ ] Архив распакован в папку на диске (не в `Program Files`) — приложение запускается и работает
- [ ] Запуск с флешки (FAT32/exFAT) — работает, данные пишутся рядом с exe

Проверка «без Qt и VC++»:

- [ ] Windows Sandbox (Win11 Pro/Enterprise): скопировать распакованную папку в песочницу и запустить `Veterans.exe` — работает без установки Qt
- [ ] Либо чистая машина без Qt/VC++ — то же самое

Установщик:

- [ ] `installer\veterans.iss` собран в Inno Setup (`ISCC.exe installer\veterans.iss`)
- [ ] Установка проходит, ярлыки «Пуск» и рабочего стола созданы
- [ ] Данные лежат в `%LOCALAPPDATA%\Veterans`, приложение работает после установки
- [ ] Деинсталляция удаляет программу и **не** удаляет базу
- [ ] Обновление поверх установленной версии сохраняет данные (проверить на копии базы)
- [ ] SmartScreen предупреждает о неподписанном exe — ожидаемо, записать текст предупреждения

## 6. Печать — M8-06, M12-04

Подготовка: 3–5 записей, среди них одна с длинным ФИО и пустыми полями, отметить
галочками. Сверить с `docs/PRINT-LAYOUT.md`.

Список («Печать → Записи в списке»):

- [ ] Открывается предпросмотр, выбирается принтер, копии и ориентация
- [ ] Масштаб 100 %, A4 альбомный
- [ ] Поля 15 мм, 7 колонок, шапка «№ / ФИО / Мкр. / Год рожд. / Льготная категория / Год посещ. / Подписка»
- [ ] Шапка повторяется на каждой странице, внизу «Стр. X из Y»
- [ ] Колонки не обрезаны справа, длинное ФИО переносится внутри ячейки
- [ ] Пустые значения печатаются как «—»
- [ ] Оттиск не обрезан по краям, текст читаем

Карточки («Печать → Каждую отдельно»):

- [ ] Одна карточка = одна страница A4 книжная
- [ ] Поля 20/15/15/15 мм, ФИО в рамке, номер записи с ведущими нулями
- [ ] Телефон в формате `X-XX-XX` или `+7XXXXXXXXXX` и подпись типа
- [ ] Подвал: дата формирования и линия для подписи, нумерации страниц нет
- [ ] Длинная карточка (длинное ФИО/адрес) переносится на 2 страницы без обрыва текста

- [ ] Печать из формы записи (кнопка «Печать» после сохранения) совпадает с макетом

## 7. Excel и PDF — M12-05

- [ ] «Файл → Экспорт в Excel» для трёх областей: отмеченные / все / результат фильтра
- [ ] Файл открывается в Excel **без** предупреждений и «восстановить содержимое»
- [ ] Открывается в LibreOffice без предупреждений
- [ ] Шапка закреплена (первая строка не уезжает при прокрутке), автофильтр работает
- [ ] Ширины колонок, заливка шапки, жирный шрифт, границы, чередование строк на месте
- [ ] Кириллица, «ё», дефисы и апострофы в ФИО не искажены
- [ ] «Файл → Экспорт в PDF» формирует файл, он открывается в Adobe Reader и в браузере
- [ ] Кириллица в PDF отображается и корректно копируется как текст
- [ ] Имя файла по умолчанию содержит область и дату, папка запоминается между запусками
- [ ] Экспорт в занятый файл (открыт в Excel) даёт понятную ошибку, а не падение

## 8. Приёмка — M12-08

Критерии из `docs/PLAN.md` §7:

- [ ] 1. На чистой Windows 10/11 приложение запускается из portable-папки без установки чего-либо ещё
- [ ] 2. Создание, правка, удаление, сортировка по 7 столбцам, быстрый и расширенный поиск работают по ТЗ
- [ ] 3. «Печать» неактивна без отмеченных строк, отмеченные строки подсвечены
- [ ] 4. Печать списка и карточек даёт макеты из `docs/PRINT-LAYOUT.md`, принтер выбирается в диалоге, предпросмотр есть
- [ ] 5. Excel-файл открывается без предупреждений и сохраняет оформление
- [ ] 6. Файл БД можно скопировать на другой ПК и продолжить работу
- [ ] 7. Автобэкап создаётся раз в сутки, восстанавливается через настройки
- [ ] 8. Светлые темы, текст читаем при многочасовой работе

Фиксация версии:

- [ ] Версия в «О программе» и в свойствах exe совпадает с `project(VERSION)`
- [ ] Приёмочный прогон подписан заказчиком, версия 1.0 зафиксирована
